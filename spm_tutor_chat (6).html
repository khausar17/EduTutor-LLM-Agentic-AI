Sine Rule
a/sin A = b/sin B = c/sin C
Use when: side-angle pair known + one more angle or side
Cosine Rule
a² = b² + c² - 2bc cos A
b² = a² + c² - 2ac cos B
c² = a² + b² - 2ab cos C
Use when: 2 sides + included angle, or all 3 sides known
Area
Area = ½ × a × b × sin C
Use when: 2 sides + included angle known
Heron's Formula
s = (a + b + c) / 2
Area = √s(s-a)(s-b)(s-c)
Use when: all 3 sides known, no angle given
Ambiguous Case (SSA)
h = b × sin A
If a < h → no triangle
If a = h → one right triangle
If h < a < b → two triangles
If a ≥ b → one triangle
